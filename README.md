## GitHub Pages ile yayınlama
1. GitHub'da yeni bir depo açın ve bu dosyaları yükleyin.
2. Settings > Pages bölümünde Source: "Deploy from a branch", Branch: main, klasör: / (root) seçin.
3. Birkaç dakika sonra canlı bağlantı yukarıdaki biçimde açılır; bağlantıyı bu README'ye yazın.
